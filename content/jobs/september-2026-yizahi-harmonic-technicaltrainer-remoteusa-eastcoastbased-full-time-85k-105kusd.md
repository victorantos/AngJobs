Harmonic - Technical Trainer - REMOTE (USA, East Coast based) - Full-time - 85k-105k USD

Key requirements: Up to 50% time can be mandatory travel for on-site in-person training sessions, very variable across the year. But no requirement to work in the office. Corollary to that - fluent or very good spoken English level is required. (PS: in actual practice it&#x27;s about 1-2 work weeks every 2 months or so, irregularly)

Harmonic is a telecom hardware vendor. We are making hardware for the DOCSIS cable, PON fiber and mixed deployments.

Technical Trainer specialist is responsible for the presenting to the customer (MSOs) technical specialists, field technicians etc. the full overview of all possible product offerings by Harmonic, the full technical overview of every possible deployment (depending on the client&#x27;s requirements) and full configuration for all hardware involved, including 3rd-party hardware. So no debugging and accessing code is needed, but if anything is customer facing, it must be explained.

As a brief example:

- Configuration for the DOCSIS core;
- Configuration for the PON core;
- Video streaming config;
- Network L2&#x2F;L3 switching configuration for multiple vendors;

The other half of the responsibilities is creating training materials, both text and graphics (designer is assisting our team too). Recording live narrated sessions too.

A familiarity with networking and&#x2F;or DOCSIS is required. Both would be great.
