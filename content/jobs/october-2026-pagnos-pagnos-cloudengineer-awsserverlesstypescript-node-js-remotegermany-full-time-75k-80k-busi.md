PAGNOS - Cloud Engineer, AWS Serverless (TypeScript&#x2F;Node.js) - REMOTE (Germany) - Full-time - €75k–80k - business-fluent German required

We build serverless applications on AWS for clients and for our own SaaS products. On client projects, we work directly with their developers and help them understand and maintain what we build.

You’ll write backend code in TypeScript&#x2F;Node.js, build APIs with Lambda and API Gateway, model data in DynamoDB, and design event-driven workflows and integrations. Infrastructure lives in code using AWS CDK, with CI&#x2F;CD pipelines for builds and deployments. You’ll help decide how systems are designed and take testing, observability and security into account as you build. There’s some React&#x2F;Next.js work too.

We’re looking for practical experience building AWS serverless applications with TypeScript&#x2F;Node.js, including infrastructure as code, CI&#x2F;CD and event-driven design. The role includes working through requirements and technical decisions with clients, so you should be comfortable with that.

We use coding agents daily and expect you to use them too, and to share useful approaches with other developers. AWS serverless development is the main focus of the role.

We’re remote-first, use Scrum, and work with code reviews, pair programming, and unit and integration tests. We meet in person regularly, sometimes in Cologne, sometimes in Austria or Mallorca. We plan travel around family commitments.

You must be based in Germany and speak business-fluent German and good English. We don’t offer visa sponsorship.

€75k–80k, 32 days of vacation, hardware of your choice, and company-paid AI tool subscriptions.

Send your CV to recruiting@pagnos.com – no cover letter needed. Questions before applying are welcome.
