Spore.Bio - Senior Software Engineer - Paris, France - Hybrid (Flexible)

Spore.Bio is a deeptech startup building a new paradigm in quality control for FMCG (Food &amp; Beverage, Cosmetics, Pharma). We are replacing 200-year-old microbiology methods with advanced optics and deep-learning technologies to detect bacterial contamination directly on the factory floor in minutes, instead of days.

We are looking for a hands-on Senior Software Engineer to design, build, and operate our core backend systems, APIs, data pipelines, and cloud infrastructure. You will be a key technical contributor, building the systems that connect our cutting-edge optical instruments to cloud data platforms.

Tech Stack: Python (FastAPI), PostgreSQL, AWS, Terraform, Ansible, Docker, GitHub Actions

If you are interested in applying software engineering to real-world hardware and microbiology challenges, we&#x27;d love to hear from you!
