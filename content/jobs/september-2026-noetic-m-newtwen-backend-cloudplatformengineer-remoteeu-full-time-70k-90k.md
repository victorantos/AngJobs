Newtwen - Backend &amp; Cloud Platform Engineer - REMOTE (EU) - Full-time - €70k–€90k+

Newtwen is building a cloud platform that brings complex physics and data-driven intelligence directly onto microcontrollers, generating ultra-fast runtime firmware that executes in just a few microseconds.

We&#x27;re looking for a Senior Backend &amp; Cloud Platform Engineer to help architect and build our first production-grade cloud backend from the ground up. You&#x27;ll own backend services and computational pipelines spanning 3D geometry processing, mesh generation, model order reduction, calibration and neural network training.

A core part of the platform is dedicated to data-driven modeling, with a specialized neural-model library designed to make physical models adaptive in real time.

You might be a good fit if you have: strong production backend&#x2F;cloud experience, Python (FastAPI or similar), relational databases, Docker, cloud infrastructure (GCP preferred), CI&#x2F;CD and IaC — and enjoy making architecture decisions rather than just implementing tickets.

Location: REMOTE (EU), with the option to work hybrid in Italy
Compensation: €70k–€90k+, depending on experience

Apply: career@newtwen.com — mention Hacker News and include your LinkedIn&#x2F;CV and, if available, GitHub or project links.
