We&#x27;re looking for an experienced embedded UI engineer to help design the UI architecture and build a polished animated interface that runs within tight memory and performance constraints.

You&#x27;ll work on:

Embedded UI architecture
Character animations and state transitions
Sprite, bitmap and font pipelines
Rendering optimization (dirty rectangles, partial redraws, partial refresh)
Display and hardware trade-offs
Integrating Git activity, build status and notifications into the UI

We&#x27;re looking for someone with experience in:

C&#x2F;C++
Embedded graphics
LVGL, U8g2, TFT_eSPI, Adafruit GFX or similar
OLED, TFT or e-paper displays
